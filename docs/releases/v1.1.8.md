## Changes since v1.1.7

### New features

- **Request a song from Add:** search a song catalog with covers and album details, choose the recording you want, and submit it to the shared wanted list. Songs already in your library are marked. Requests do not automatically download audio.
- **Endless Next:** continue with library recommendations when the queue ends, then cycle playable songs after the finite library is exhausted. Continuation keeps a bounded queue and avoids an immediate repeat when alternatives exist. Offline skips select saved or cached songs.
- **Playlist backgrounds:** normal playlists and Spotify imports share a broad gradient drawn from their playlist picture, fading into the page. Changing the picture changes the tint.
- **Identify a song:** use “Find by lyrics or translated title” in Search to identify approximate titles, translated names or remembered lyrics, match library copies, and request missing recordings. Ordinary local search stays instant; full-width character matching is improved.
- **Ask Yomi web search:** the assistant can retrieve web results and display source links. Public search works without an additional key; a Brave Search API key can be used instead. The existing Yomi conversational persona is preserved.
- **Optional volume boost:** choose Off, +3 dB or +6 dB from a song's three-dot menu. A separate copy applies gain and peak limiting without changing the original audio. Boost applies per song for the current session; preparing it requires connectivity.

### Fixes and reliability

- Queued songs that finish downloading switch to local playback reliably, including with shuffle enabled. Rapid skip taps continue to replace pending loads.
- Prefer synced lyrics over plain lyrics from another provider, recheck older plain-lyrics caches, and retry uncertain lookups.
- Preserve artwork version IDs so repaired covers replace stale cached images. Artwork matching now retains non-Latin artist/title identities instead of collapsing them together.
- Preserve the Apple HTTP networking configuration used by native audio playback.
- Server uploads use consistent hash-based duplicate protection across legacy and bulk routes.
- Album-cover repair requires matching artist and album metadata, avoiding shared artwork across unrelated recordings.
- Replica synchronization preserves append-only chats/history when the primary's copy is missing or shorter. Backup commands use the host's shell.

### Downloads and requirements

- **Android:** signed APK.
- **macOS:** app ZIP.
- **Linux:** x86_64 AppImage.
- **iOS:** unsigned IPA for signing with your own Apple credentials or sideloading tool. This is not an App Store/TestFlight build and cannot be installed directly without signing.

Every download includes a SHA-256 checksum. Web search, lyric/translated-title identification and volume boost require the updated Yomi service. Search defaults to public result snippets or uses Brave when `YOMI_SEARCH_KEY` is configured. Volume boost requires server-side ffmpeg. Self-hosted users should update the server alongside the app.

Release source is based on feature commit `9943d05`, plus version and cross-platform packaging changes. No alternate app icons are included.
