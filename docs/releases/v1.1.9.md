## Changes since v1.1.8

### Fixes and reliability

- MP3s without embedded artwork now show an exact-match cover instead of a blank one; real artwork added later still takes over.
- Playlist covers, profile pictures, banners and song-request covers are kept on the device, so they load instantly and offline.
- Live messages no longer stop for good after an unexpected server reply.
- Keychain saving keeps working after one failed write.
- Changes made while offline are no longer applied twice after a timeout.
- Scrobble queue saves no longer overlap; the catalog cache isn't rewritten after sign-out; boosted audio is deleted on sign-out; idle connections are closed.
- Playing from Recently added no longer changes the queue as more songs load.

### Security

- Automatic home-server discovery only scans the saved home network, so the login is never sent to devices on other Wi-Fi networks.
- The login screen warns when a server address isn't encrypted.
- Login tokens no longer appear in connection error messages.
- User names are encoded in messaging URLs.
